# atcoder_rated_or_unrated
ratedにするかunratedにするか過去のatcoderの結果からルーレットで決めてくれます。

これはAtCoder非公式のツールです。AtCoder株式会社とは関係がありません。

## Reference

Performanceの補正方法の実装にあたり、[AtCoder Rating Estimator](https://github.com/3w36zj6/atcoder-rating-estimator) を参考にしています。

AtCoder Rating Estimator is licensed under the MIT License.

## データの取得について

「AtCoderから取得」を使用すると、入力したAtCoderユーザー名を利用して、AtCoder Problemsの公開APIからRating履歴を取得します。

入力したユーザー名や取得したデータを、このサイト独自のサーバーに保存することはありません。
